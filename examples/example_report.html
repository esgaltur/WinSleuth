Known-vulnerable driver loaded: RTCore64.sys

High87

This driver is signed and therefore loads normally, but exposes privileged memory, MSR or port I/O access to any user-mode process. Such drivers are routinely brought along by attackers specifically to disable security software from the kernel, and they are a common source of instability in their own right. The mitigations that would block a known-vulnerable driver from loading are disabled on this machine, and such a driver is loaded right now.

Evidence
  • RTCore64.sys at C:\Windows\System32\drivers\RTCore64.sys
  • RTCore64.sys (MSI / RivaTuner Statistics Server) exposes arbitrary kernel memory read/write and MSR access from user mode. Loaded builds of this driver are routinely used to disable security software and escalate to kernel. Note this match is by file name — a patched build may carry the same name.
  • Referenced as CVE-2019-16098
  • Memory Integrity (HVCI) is switched off, so nothing prevents this driver being loaded and abused.
  • Memory Integrity (HVCI) is off
  • the Microsoft vulnerable driver blocklist is off

What to do

Uninstall the software that installed this driver if you do not need it, and switch on Memory Integrity so Windows blocks known-vulnerable drivers.

  • Set-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\CI\Config' -Name VulnerableDriverBlocklistEnable -Value 1Turn on the vulnerable driver blocklist
  • start windowsdefender://coreisolationOpen Core Isolation settings
